A · Same four cards, half the rows

Keep today’s model and card order; change only how controls sit. Labels move to a left column, as in Keynote’s and Pages’ Format inspectors, so a row is one line instead of two. Values that were footers move into the controls (pixel size in the card header, layout width as the slider’s readout). Four-word text segments become pop-ups; Light/Dark becomes a sun/moon pair in the Page header. Rarely used Desktop settings go into a closed disclosure group. Lowest risk; the frame is still chosen with two switches and a segment.

Replaces: Device segment (always automatic), Scale segments (pop-up beside the dimensions), Zoom + footer (Page Width slider in px), Auto Padding switch (Padding slider defaulting to Auto), Shuffle / Image… / Center Window / Fill Desktop text buttons (icon buttons and swatch tiles), drag hint. Keeps: Output · Page · Safari Window · Backdrop, both header switches, Canvas/Desktop choice.

B · One frame picker Recommended

Today the frame is picked in three places: the Safari Window switch, the Backdrop switch, and the Canvas/Desktop segment. Replace all three with one row of four thumbnails: Page, Safari, Canvas, Desktop. The thumbnail shows the result, so no explanation is needed, and the cards below show only what the chosen frame uses. Everything that is part of the frame (background, padding or window size, shadow) sits in one Frame card under the picker; the browser chrome (address, tab bar) gets its own Window card, shown only when a Safari window is drawn. Settings the app can work out (device, menu bar appearance) stop being inspector controls; menu bar text is edited on the canvas, like the custom address already is.

Replaces in today’s model: the window × backdrop pair as UI (stored Look fields stay; tiles map Page = none/none, Safari = safari/none, Canvas = either/canvas, Desktop = safari/desktop), Device (always automatic), Menu Bar appearance (automatic; Frame menu keeps Light/Dark), App Name and Clock fields (click on the canvas, plus Frame ▸ Menu Bar Text…), Zoom (shown as Page Width in px), Auto Padding switch, all four text buttons and all three explanatory lines.

Screen · Safari, iPhone sizeSafari on iPhone is drawn because the size is an iPhone. iPhone has no tab bar, so its row becomes Minimized Bar. Desktop is disabled for phone and tablet sizes.
Size pop-up. Grouped presets, then a separator and Custom. Custom is checked when W × H match no preset; typing in either field selects it.

Menu bar. Every removed control keeps its Frame menu item (F9), disabled when it doesn’t apply.

C · The canvas frames, the inspector follows the selection

Treat the frame as objects on the canvas, as Keynote and Pixelmator Pro do. A floating glass bar under the image picks the frame and background; clicking the backdrop or the window chrome selects it, and the inspector shows that object’s card under the always-present Size and Page cards. Padding is dragged from the canvas edges and the window from its toolbar, each with a live badge. The live page itself can’t be selected, because clicks there go to the website. That is the main cost: the frame’s settings are out of sight until you click the right object, and every selection state needs a menu equivalent.

Replaces: everything B replaces, plus the Frame card (moves to the glass bar and to selection), the header switches, and the always-visible Background grid. New concept: a selection on the canvas (Backdrop, Window, or none), which today’s model doesn’t have.
